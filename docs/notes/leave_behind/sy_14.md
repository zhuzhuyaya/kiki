# MinIO 对象存储

> 课程封面/图集落对象存储，数据库只存 URL。`course.cover` 存的是 `http://.../shiyi/2026/10/30/xxx.png` 这种地址。

## 为什么放对象存储（面试标准讲法）

| 方案 | 问题 |
| --- | --- |
| 数据库存 BLOB | 备份慢、连接长时间占用、库膨胀到没法运维——图片永远不该进 MySQL |
| 本地磁盘 | 多实例部署时文件散落各机；应用无状态化是水平扩展的前提 |
| 对象存储（MinIO/S3/OSS） | 水平扩容、自带 HTTP 访问、可挂 CDN、应用只存 URL |

一句话版本：**文件放对象存储，数据库只存 URL**。

## 前置：建桶 + 公读规则

控制台（localhost:9001）→ Object Browser → Create Bucket `shiyi`（小写）→ 点进桶 → Anonymous → Add Access Rule：prefix `/`、Access `readonly`。课程封面人人可见，URL 直接打开。

::: tip 公读 vs 私有
公开内容（课程封面）用公读桶 + 永久 URL；**隐私文件**（身份证、合同）必须私有桶 + `presignedGetObject` 预签名临时链接。取舍是存储安全面试题。
:::

```xml
<dependency>
    <groupId>io.minio</groupId>
    <artifactId>minio</artifactId>

```

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 10MB      # 默认只有 1MB，不改传图必炸
      max-request-size: 20MB

minio:
  endpoint: http://localhost:9000
  access-key: minioadmin
  secret-key: 你的密码
  bucket: shiyi
```

::: warning
`multipart` 要嵌在已有的 `spring:` 块里，yml 出现两个顶级 `spring:` 是新手高频错误。
:::

## 属性类 + 客户端 Bean

```java
@Data
@Component
@ConfigurationProperties(prefix = "minio")
public class MinioProperties {
    private String endpoint;
    private String accessKey;
    private String secretKey;
    private String bucket;
}
```

```java
@Configuration
public class MinioConfig {

    @Bean
    public MinioClient minioClient(MinioProperties properties) {
        return MinioClient.builder()
                .endpoint(properties.getEndpoint())
                .credentials(properties.getAccessKey(), properties.getSecretKey())
                .build();
    }
}
```

`@ConfigurationProperties` 比 `@Value` 散着注入好：类型安全、IDEA 补全、集中管理。配置项一多就用它。

## 上传服务

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class MinioService {

    private final MinioClient minioClient;
    private final MinioProperties properties;

    /** 上传图片，返回可公开访问的 URL */
    public String upload(MultipartFile file) {
        if (file == null || file.isEmpty()) {
            throw new BusinessException("请选择文件");
        }
        String original = file.getOriginalFilename() == null ? "" : file.getOriginalFilename();
        int dot = original.lastIndexOf('.');
        if (dot < 0) {
            throw new BusinessException("文件缺少扩展名");
        }
        String ext = original.substring(dot + 1).toLowerCase();
        // 白名单制：只放行认识的类型
        if (!List.of("jpg", "jpeg", "png", "webp").contains(ext)) {
            throw new BusinessException("仅支持 jpg/png/webp 图片");
        }

        // 日期目录 + UUID：防覆盖、防猜路径、原始名不落盘
        String objectName = LocalDate.now().toString().replace("-", "/")
                + "/" + UUID.randomUUID().toString().replace("-", "") + "." + ext;

        try (InputStream in = file.getInputStream()) {
            minioClient.putObject(PutObjectArgs.builder()
                    .bucket(properties.getBucket())
                    .object(objectName)
                    .stream(in, file.getSize(), -1)   // 已知大小 → 单次 PUT，-1 分片自动
                    .contentType(file.getContentType())
                    .build());
        } catch (Exception e) {
            log.error("MinIO 上传失败", e);
            throw new BusinessException("上传失败，请稍后重试");
        }
        return properties.getEndpoint() + "/" + properties.getBucket() + "/" + objectName;
    }
}
```

四个安全/工程点（都可能被追问）：

1. **白名单不是黑名单**：拦"认识的危险类型"追不全，只放行认识的类型才对
2. **UUID 重命名 + 原始名不落盘**：原始名可能超长/带特殊字符/是攻击载荷；UUID 路径不可猜、永不覆盖
3. **日期目录**：海量文件按日期归档，好管理
4. **try-with-resources**：流自动关闭

日志分级：技术失败（连不上 MinIO）→ error + 模糊提示；用户问题（类型不对）→ 明确业务提示。

## 通用上传接口 + 封面回填

```java
@RestController
@RequestMapping("/api/v1/files")
@RequiredArgsConstructor
public class FileController {

    private final MinioService minioService;

    @PostMapping("/upload")
    public Result<String> upload(@RequestParam("file") MultipartFile file) {
        return Result.ok(minioService.upload(file));
    }
}
```

不写任何鉴权注解——全局拦截器默认全锁，新接口天然受保护。放在 `infra` 包：纯技术能力，不属于业务域。

封面回填（属主校验直接复用）：

```java
@Override
public String updateCover(Long courseId, MultipartFile file) {
    Course course = getMyCourse(courseId);          // 越权防护零成本获得
    String url = minioService.upload(file);
    course.setCover(url);
    courseMapper.updateById(course);
    return url;
}
```

## 验证清单

1. form-data 上传图片 → 返回 URL，浏览器能打开
2. 传 `.txt` → 400"仅支持 jpg/png/webp"
3. 不带 token → 401
4. 对自己课程设封面 → cover 字段回填 URL
5. C 对 B 的课程设封面 → "课程不存在"（属主层）
6. 传 >10MB → 500（可选：单独 handler 返回 400"图片过大"）

## 小结

- 文件放对象存储、数据库只存 URL，是多实例部署的基石
- 上传四件套：白名单、UUID、日期目录、限流控制大小（multipart 默认 1MB）
- `@ConfigurationProperties` 管配置，`infra` 包放三方封装
